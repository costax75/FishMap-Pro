# FishMap Pro

Вебпроєкт для створення карти водойм і промірів глибин.

## Файли

- `index.html` — головна сторінка.
- `style.css` — оформлення.
- `app.js` — логіка карти.
- `README.md` — опис проєкту.

## Що вже працює

- Leaflet + OpenStreetMap.
- Додавання промірів глибини.
- Вибір типу дна.
- Кольорові точки залежно від глибини.
- Збереження даних у `localStorage`.
- Окремі водойми.
- Картка активної водойми.
- Кольорове промальовування рельєфу.
- Лінії перепаду глибин / бровок.
- Аналіз точки для флет-фідера.
- Автоматичний рейтинг найперспективніших точок для флету.

## Важливо

Збереження через `localStorage` працює окремо на кожному пристрої та браузері.
Для синхронізації між телефонами/комп'ютерами пізніше потрібно підключити базу даних.

## Запуск

Відкрий `index.html` у браузері.

Для повноцінного онлайн-проєкту найкраще опублікувати репозиторій через GitHub Pages.

- Підбір насадки, поп-апа, бойла та корму під вибрану рибу і промір.

- Погода для активної водойми: температура, тиск, вітер, опади та погодний індекс.

Погодні дані отримуються через Open-Meteo Forecast API; документація: https://open-meteo.com/en/docs
